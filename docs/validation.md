# 검증 결과 · 2026-11-12

## 실제 실행 환경

Windows 11, Python 3.12, FastAPI 0.162.5, psycopg 3.3.8, PostgreSQL 17(Docker), Edge/Playwright. AI 모드 `demo`. 모든 자동 검증은 실제 PostgreSQL을 사용했으며 SQLite로 대체하지 않았다.

## 통합 검증

`python -m pytest -q --tb=short`로 별도의 임시 스키마에서 다음을 확인했다.

1. 가입·로그인·프로필 수정, 중복 회원 409, 위조/미인증 토큰 401, 입력 오류에 비밀번호가 반사되지 않음.
2. 주제 조회, 세션 생성·조회·수정·삭제, 대화 저장, 문제 생성, 반복 풀이·피드백, 타인의 모든 하위 경로 접근 404, 50% 정답률·정확한 세션 수, CASCADE 삭제.
3. A/B 결과 저장·재조회·권한·삭제, B 호출 실패 시 실험 레코드 미생성.
4. AI 대화 실패 시 사용자 메시지만 남지 않음, 잘못된 AI JSON·불리언 거절.
5. 같은 세션에 동시에 두 대화를 보내도 user/assistant 순서의 두 쌍으로 저장.
6. 8개 테이블·8 PK·7 FK, 없는 부모·허용되지 않은 상태/역할/variant·A/B 중복·사용 중인 주제 삭제 거절, seed 재실행 시 시퀀스 보존.
7. 비밀번호 변경 후 이전 토큰 거절, 현재 비밀번호 확인, 탈퇴 시 소속 세션·실험 제거.
8. 정적 화면·JS·CSS·아이콘·API 문서 제공, .env·SQL 웹 접근 차단, CSP·no-store 헤더.

추가 검증에는 `queries.sql` 전체 SQL CRUD 시연 및 롤백, Gemini HTTP 요청 형식·키 헤더·오류 비노출을 가짜 HTTP 응답으로 검증하는 테스트를 포함한다. 정확한 최종 통과 개수는 아래 실행 기록에 남긴다.

## 실제 브라우저 검증

- 공개 시연 계정 로그인, 주제 선택·세션 생성, 질문·응답 저장.
- 문제 생성 → 오답 제출 → 정답 재제출, 두 시도 모두 표시.
- 세션 제목·상태 수정, 완료 세션 입력 차단, 학습 기록 재열기·새로고침 후 복원.
- 통계와 A/B 실험 결과·이력 표시, 내 계정 화면.
- HTML 형태의 세션 제목이 실행되지 않고 텍스트로 표시됨.
- 로그아웃 후 새 회원으로 가입해도 이전 계정의 실험 결과가 화면에 남지 않음.
- 390×844 모바일에서 가로 넘침 없음.
- 화면 전환 중 늦게 도착한 세션 조회 응답이 다른 화면으로 되돌리지 않도록 수정 후 재확인.
- 화면 10장을 `docs/screenshots/`에 저장. 자동 시연에서 만든 레코드는 검증 후 삭제하고 기본 seed는 보존.

## 검증 제한

실제 Gemini 키·유료 호출은 사용하지 않았다. 모의 HTTP 테스트는 요청·오류 처리 검증이며 모델 정확성·안전성·실제 모델 지원 여부를 증명하지 않는다. 오프라인 데모는 고정 예시와 단답 일치 채점이다. 부하·분산 인증 제한·외부 인터넷 배포·장애 복구·장기 백업 검증은 범위에 포함하지 않았다. 테스트 의존성에서 httpx 사용에 관한 Starlette deprecation 경고가 발생하며 현재 검증은 통과한다.
