# 테이블 명세서 · PostgreSQL 17

실행한 DB의 `information_schema`와 제약조건을 조회해 생성했다. 기준 SQL은 `database/schema.sql`. 정확히 8개 테이블·8 PK·7 FK다.

번호는 `GENERATED BY DEFAULT AS IDENTITY`이며, 각 시퀀스가 자동 생성한다. TIMESTAMPTZ는 시간대를 포함하며 화면에서 한국 시간으로 표시한다.

## 회원 (users)

| 속성 이름 | 코드 컬럼 | 데이터 타입 | NULL 허용 | 기본값 | PK | FK |
|---|---|---|---|---|---|---|
| 회원아이디 | user_id | CHARACTER VARYING(50) | N | — | PK | — |
| 비밀번호 해시 | password_hash | CHARACTER VARYING(255) | N | — | — | — |
| 이름 | name | CHARACTER VARYING(50) | N | — | — | — |
| 이메일 | email | CHARACTER VARYING(254) | N | — | — | — |

제약조건:

- `CHECK (((email)::text ~ '^[^[:space:]@]+@[^[:space:]@]+[.][^[:space:]@]+$'::text))`
- `CHECK ((length(btrim((name)::text)) > 0))`
- `CHECK ((length((password_hash)::text) > 20))`
- `CHECK (((user_id)::text ~ '^[A-Za-z0-9_]{3,50}$'::text))`

## 학습세션 (sessions)

| 속성 이름 | 코드 컬럼 | 데이터 타입 | NULL 허용 | 기본값 | PK | FK |
|---|---|---|---|---|---|---|
| 세션번호 | session_id | INTEGER | N | IDENTITY 자동생성 | PK | — |
| 회원아이디 | user_id | CHARACTER VARYING(50) | N | — | — | users.user_id |
| 주제번호 | topic_id | INTEGER | N | — | — | topics.topic_id |
| 세션제목 | title | CHARACTER VARYING(200) | N | — | — | — |
| 시작일시 | started_at | TIMESTAMP WITH TIME ZONE | N | CURRENT_TIMESTAMP | — | — |
| 학습상태 | status | CHARACTER VARYING(20) | N | 'in_progress'::character varying | — | — |

제약조건:

- `CHECK (((status)::text = ANY ((ARRAY['in_progress'::character varying, 'completed'::character varying, 'stopped'::character varying])::text[])))`
- `CHECK ((length(btrim((title)::text)) > 0))`
- `FOREIGN KEY (topic_id) REFERENCES topics(topic_id) ON DELETE RESTRICT`
- `FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE`

## 실험결과 (experiment_results)

| 속성 이름 | 코드 컬럼 | 데이터 타입 | NULL 허용 | 기본값 | PK | FK |
|---|---|---|---|---|---|---|
| 결과번호 | result_id | INTEGER | N | IDENTITY 자동생성 | PK | — |
| 실험번호 | experiment_id | INTEGER | N | — | — | prompt_experiments.experiment_id |
| 설정유형 | variant | CHARACTER(1) | N | — | — | — |
| 프롬프트 | prompt | TEXT | N | — | — | — |
| AI 응답내용 | response | TEXT | N | — | — | — |

제약조건:

- `FOREIGN KEY (experiment_id) REFERENCES prompt_experiments(experiment_id) ON DELETE CASCADE`
- `UNIQUE (experiment_id, variant)`
- `CHECK ((length(btrim(prompt)) > 0))`
- `CHECK ((length(btrim(response)) > 0))`
- `CHECK ((variant = ANY (ARRAY['A'::bpchar, 'B'::bpchar])))`


## 서비스 규칙

비밀번호는 Argon2id 해시, 문제 정답은 최초 목록에서 제외한다. 풀이 이력은 갱신하지 않고 매 제출마다 새 행을 저장한다. `is_correct=NULL`은 채점 대기이며 현재 API는 채점 완료된 결과만 저장한다. A/B 각 1개의 완성 여부는 API 트랜잭션으로 보장한다. 상세 삭제·통계 기준은 `relational_schema.md`를 참고한다.
